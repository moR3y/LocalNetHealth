# LocalNetHealth 1.0.0

Initial public release.

- Version: 1.0.0
- Platform: Windows x64
- License: Freeware
- Japanese UI
- Source code is not distributed in this repository.

## Included functionality

- Local / LAN Mode
- Viewer / Admin
- Optional Admin TOTP
- Recovery Codes
- LAN QR access
- Network monitoring and history
- Alerts and device observation
- Backup / runtime export
- Windows Installer

- LAN Mode is for trusted private networks and is not intended for Internet exposure.

- Security vulnerabilities must not be reported through public Issues. Use GitHub Private Vulnerability Reporting after the maintainer confirms it is enabled.
